# ⚡ VCL-Light (Vitson Content Lab - Light)
> **(주)일신비츠온 1인 올인원 콘텐츠 제작자를 위한 기획 / 대본 / 자막 / AI 영상 제작 지원 스튜디오**

---

## 📌 개요
VCL-Light는 (주)일신비츠온의 대표 브랜드 **비츠온(Vitson)**, **홈빛(Homevit)** 및 **비츠온MRO** 공식 취급 제품들을 기반으로 기획 아이템을 추천받고, 정밀 제원과 상세페이지를 분석하여 유튜브 쇼츠·릴스·롱폼 대본 및 자막, AI 영상 프롬프트를 원스톱으로 제작할 수 있는 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

### 1. 🎲 비츠온MRO 기준 아이템 5개 랜덤 추천 & 다시 뽑기
- 실제 [비츠온MRO](https://vitsonmro.com/)에서 판매 중인 220여 종의 실제 정품 카탈로그 기반 추천
- **브랜드 필터링**: `[전체]` / `[비츠온(Vitson)]` / `[홈빛(Homevit)]` / `[공구·MRO]`
- **다시 추천 받기 🎲** 버튼으로 언제든 새로운 아이템 5종 셔플
- 제품명, 모델명, 비츠온MRO 상품코드 직접 검색 지원

### 2. 📋 제품 상세 제원 & Gemini AI 심층 분석
- **상세 제원표**: 소비전력(W), 색온도(K), 외형 치수, 타공 규격, 광속(lm), 연색성, 인증번호 등 정밀 스펙 출력
- **비츠온MRO 바로가기**: 공식 상세페이지 1클릭 연결
- **Gemini 3.6 Flash 기반 AI 분석**:
  - 💡 **1줄 핵심 가치 요약**
  - 🎯 **추천 타겟 페르소나** (셀프인테리어족, 전기기사, 상가 사장님 등)
  - ⭐ **스펙 기반 핵심 셀링포인트(USP)**
  - 🔥 **숏폼/릴스 추천 바이럴 훅(Hook) 5종** 및 원클릭 복사

### 3. ✍️ 스마트 대본 에디터 & 메모장 (좌우 분할 스튜디오)
- **좌우 분할(Split) 작업 환경**: 좌측 제품 제원 및 AI 도우미 / 우측 대본 에디터 및 메모장
- **예상 영상 재생 시간 계산기**: 한국어 발화 속도(초당 5.2음절) 기반으로 쇼츠 60초 최적화 여부 실시간 게이지 표시
- **원클릭 제작 보조 툴바**:
  - `[📋 스펙 삽입]`: 선택된 제품 제원을 깔끔하게 대본에 삽입
  - `[📑 템플릿 적용]`: 원하는 대본 템플릿의 변수를 현재 제품 정보로 자동 치환하여 적용
  - `[⚡ AI 쇼츠 대본 (1분)]`: 45~50초 완결형 숏폼 스크립트 초안 자동 작성
  - `[🎥 AI 롱폼 대본]`: 유튜브 리뷰/설치 가이드 롱폼 대본 작성
  - `[💬 자막 분할]`: 영상 편집기(프리미어, 캡컷, Vrew)에 바로 붙여넣는 타임라인 자막 생성
  - `[🤖 AI 영상 프롬프트]`: Runway Gen-3, Kling, Sora용 B-Roll 고화질 프롬프트 생성
  - `[📄 TXT / 📝 MD]`: 대본 파일 즉시 다운로드 및 클립보드 복사

### 4. 📑 템플릿 관리 (Template Studio)
- 기본 제공 실전 템플릿 4종:
  1. `[비츠온/쇼츠] 1분 완성 스펙 & 실사용 리뷰`
  2. `[홈빛/인테리어] 감성 조명 스타일링 & 비포애프터`
  3. `[비츠온MRO/B2B] 전문가용 전기자재/공구 현장 검증`
  4. `[공통/DIY] 문제 제기 -> 스펙 해결 -> 3분 컷 설치`
- 사용자 커스텀 템플릿 등록/수정/삭제:
  - `{{제품명}}`, `{{브랜드}}`, `{{규격}}`, `{{모델명}}`, `{{소비전력}}`, `{{색온도}}`, `{{구매링크}}` 등 동적 치환 태그 지원

### 5. 📂 대본 보관함 (Firebase Firestore 실시간 연동)
- 작성한 대본을 제목, 브랜드, 제작 상태별(기획중, 대본완료, 촬영완료, 업로드완료)로 관리
- 검색, 계속 편집, 복제(Duplicate), 삭제 지원
- Cloud Firestore 실시간 영구 보관 + 로컬스토리지 오프라인 안전 백업

## 🚀 실행 및 배포 방법

### 1. 로컬에서 즉시 실행하기
프로젝트 폴더에서 다음 중 편한 방법을 선택하세요:

**방법 A. zero-dependency 로컬 서버 실행 스크립트:**
```powershell
.\start-local.ps1
```
> 브라우저에서 `http://localhost:3000/index.html`이 자동으로 열립니다.

**방법 B. VS Code / Live Server 또는 Chrome으로 열기:**
VS Code의 `Live Server` 확장으로 `public/index.html`을 우클릭하여 실행하거나, 로컬 웹서버를 구동합니다.

---

### 2. 파이어베이스 호스팅(Firebase Hosting) 배포하기
어디서든 접속할 수 있도록 `https://vcl-light.web.app`에 배포합니다:

```bash
# 1. Firebase 로그인 (최초 1회)
npx -y firebase-tools login

# 2. Firebase 호스팅 및 Firestore 규칙 배포
npx -y firebase-tools deploy
```
또는 동봉된 `deploy-firebase.ps1` 스크립트를 실행하시면 자동으로 배포됩니다:
```powershell
.\deploy-firebase.ps1
```
